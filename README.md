# GoRail Web — Railway Operations & Management

Browser implementation of the main GoRail railway-management logic.

## Features
- Passenger login/register and profile
- Train enquiry/search
- Seat availability and fare enquiry
- Passenger booking, PNR generation and ticket QR
- Ticket cancellation
- Live train status
- Station information and special trains
- Emergency help
- Food ordering
- Complaints
- Notifications
- Admin dashboard, train management and broadcast notices
- Browser localStorage persistence

## Run
Open index.html in a modern browser.

This client-only version uses localStorage. For production, connect the same entities to Firebase/Firestore or a GoRail backend.
